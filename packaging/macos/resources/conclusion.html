Bot Farm Silence Tracker is installed

Open Bot Farm Silence Tracker from the Applications folder in your home folder (in Finder: Go > Home, then Applications), or from Launchpad or Spotlight.

To use it from Terminal, open a new Terminal window and run bot-farm-silence-tracker --help.

If you had already saved a list of platforms and left only the default (Reddit archive) ticked, your saved list was kept. Check it with bot-farm-silence-tracker config show and change it with bot-farm-silence-tracker config set-platforms reddit-archive,bluesky.

To remove it later, run bot-farm-silence-tracker-uninstall in Terminal. It keeps your scans and settings unless you add --purge.
